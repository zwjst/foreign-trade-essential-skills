# Distribution status / 分发状态

## Current product boundaries

- The GitHub repository is the public source-code and documentation location.
- The ChatGPT plugin is a separately managed private plugin owned by the user.
- A public repository does not imply public plugin-directory publication.
- No public plugin-directory submission is made by this repository workflow.

## Release checklist

- [ ] Validate both Skills and all local references.
- [ ] Confirm examples contain no real customer identifiers or patient information.
- [ ] Confirm plugin manifest and repository URLs match the canonical repository.
- [ ] Confirm private plugin remains private unless the owner explicitly changes its audience.
- [ ] Review changes before tagging a release.

Never claim public plugin-directory publication without an actual approved submission and listing.
